# Кандинский для iOS

Приложение для создания фото и видео. История чатов доступна на обоих устройствах через сервер в Алматы.

## Запуск

На Mac установи Xcode 26.3. В Xcode через Settings → Components добавь среду симулятора iOS 26.3. Запусти команду из корня проекта.

```sh
./scripts/run-review.sh
```

Команда создаст симулятор iPhone 17, соберёт и откроет приложение. Следующий запуск использует тот же симулятор.

Для установки на iPhone с iOS 16 или новее выбери в Xcode схему Kandinsky, свой телефон и команду подписи. [Проект Xcode](ios/Kandinsky.xcodeproj)

## Как проверить генерацию

1. Создай отдельный чат. Выбери Image Lite, опиши фото и отправь запрос. Открой результат. Под фото нажми «Поделиться», затем «Сохранить изображение» (Save Image). Если iOS спросит разрешение, разреши сохранить снимок.
2. Выбери Video Lite. Для короткой проверки поставь 384 × 384 и 1 с. Опиши видео, отправь запрос и проиграй готовый ролик.
3. Нажми «Добавить фото или видео» и выбери «Оживить фото из галереи». Возьми сохранённый снимок, опиши движение и проиграй результат.
4. На втором устройстве войди в тот же аккаунт и открой этот чат. Отправь запрос по очереди с каждого устройства и проверь, что на другом видны прогресс и готовый файл.

Первый запуск модели может занять несколько минут.
